# 내 환율 계산 - 배포 안내

이 폴더를 무료 호스팅에 올리면 바로 폰에 설치 가능한 PWA(Progressive Web App)가 됩니다.

## 📁 파일 구성

```
exchange-calc-pwa/
├── index.html              ← 앱 본체 (React 코드 전부 포함)
├── manifest.json           ← PWA 설정 (앱 이름, 색상, 아이콘 등)
├── sw.js                   ← 서비스 워커 (오프라인 캐싱)
├── icon.svg                ← 벡터 아이콘
├── icon-192.png            ← 192px 아이콘 (Android)
├── icon-512.png            ← 512px 아이콘 (Android)
├── apple-touch-icon.png    ← iOS 홈 화면 아이콘
└── README.md               ← 이 파일
```

---

## 🚀 배포 방법 1: Netlify Drop (가장 쉬움, 회원가입 없이 가능)

PC/맥에서 진행하는 게 편합니다.

1. 브라우저에서 **https://app.netlify.com/drop** 접속
2. 이 `exchange-calc-pwa` **폴더 전체**를 드래그해서 페이지 위에 떨구기
3. 잠시 후 `https://xxxxxx.netlify.app` 같은 URL이 나옴 — 이게 여러분의 앱 주소
4. (선택) 회원가입 하면 URL을 원하는 이름으로 바꾸고 영구 보관 가능 ([Claim site] 버튼)
5. 폰 브라우저로 그 URL 접속 → 아래 "📱 홈 화면 추가" 단계 진행

**장점**: 회원가입 없이 5분 컷, HTTPS 자동 적용
**단점**: 회원가입 안 하면 24시간 후 사이트 만료 (주소 잊지 말고 회원가입 추천)

---

## 🚀 배포 방법 2: Vercel + GitHub (영구 보관, 약간 더 단계 필요)

장기적으로 쓰실 거면 이쪽 추천.

1. **GitHub 계정 만들기** — https://github.com/signup (이메일만 있으면 무료)
2. **새 저장소 만들기** — 우상단 `+` → `New repository` → 이름 자유 (예: `exchange-calc`) → `Create`
3. **파일 업로드** — `uploading an existing file` 링크 클릭 → 이 폴더 안의 파일들 모두 드래그 → `Commit changes`
4. **Vercel 계정 만들기** — https://vercel.com/signup → `Continue with GitHub` (방금 만든 계정으로 로그인)
5. **프로젝트 가져오기** — Vercel 대시보드 → `Add New...` → `Project` → 방금 만든 저장소 선택 → `Deploy`
6. 1~2분 후 `https://exchange-calc-xxx.vercel.app` URL 받음
7. 폰 브라우저로 URL 접속 → 아래 "📱 홈 화면 추가" 단계 진행

**장점**: 영구 보관, 코드 수정 시 자동 재배포, 빠른 CDN
**단점**: 계정 두 개 필요 (다 무료)

## 📱 폰 홈 화면에 추가하기

배포된 URL을 폰 브라우저로 열고 아래 절차로 홈 화면에 추가하면 일반 앱처럼 동작합니다.

### iPhone (Safari 필수, 다른 브라우저는 안 됨)

1. **Safari**로 사이트 접속
2. 하단 가운데 **공유 버튼** (네모에서 화살표 올라가는 아이콘) 탭
3. 메뉴 스크롤해서 **"홈 화면에 추가"** 선택
4. 우상단 **"추가"** 탭
5. 홈 화면에 ₩ 아이콘이 생김 — 일반 앱처럼 사용

### Android (Chrome)

1. **Chrome**으로 사이트 접속
2. 우상단 **점 3개 메뉴** 탭
3. **"홈 화면에 추가"** 또는 **"앱 설치"** 선택
4. 확인 → 홈 화면에 아이콘 생성

## 🌐 오프라인 동작 원리

- 첫 접속 시 서비스 워커가 모든 파일을 캐시에 저장 (React, 폰트, 아이콘 포함)
- 두 번째 접속부터는 인터넷 없어도 즉시 실행
- 환율은 `open.er-api.com` 무료 API에서 받아서 `localStorage`에 저장
- 캐시된 환율 날짜가 "어제 또는 오늘"이면 그대로 사용, 아니면 백그라운드로 자동 갱신
- 비행기 모드/해외 데이터 없는 곳에서도 마지막 받은 환율로 계산 가능

---

## 🛠️ 환율 직접 수정하고 싶을 때

`index.html` 파일을 텍스트 에디터로 열어서 `DEFAULT_RATES` 부분 수정:

```js
const DEFAULT_RATES = {
  USD: 1,
  KRW: 1488,  // ← 여기 숫자만 수정
  EUR: 0.852,
  ...
};
```

이건 인터넷 없을 때 폴백 값이고, 실제 사용 환율은 API에서 자동으로 받아옵니다.

## ❓ 자주 묻는 질문

**Q. 앱 스토어에 안 올리는데 진짜 앱인가요?**
A. PWA는 브라우저가 일반 앱처럼 보여주는 표준 기술입니다. 카카오톡 같은 네이티브 앱은 아니지만, 홈 화면에서 탭하면 전체화면으로 뜨고 오프라인에서도 동작해요.

**Q. 사용 중 환율이 갱신되나요?**
A. 우상단 새로고침 버튼 누르면 즉시 갱신. 그렇지 않으면 하루 한 번 자동으로 어제 환율로 갱신됩니다.

**Q. 데이터 안 쓰고 싶어요.**
A. 출국 전 한 번 새로고침해서 최신 환율 받아놓으세요. 이후 비행기 모드로 두고 사용 가능합니다.

**Q. 환율 정확도는?**
A. `open.er-api.com`의 표준 환율 사용 (시중 은행 환전 시 적용 환율과는 1~3% 차이 날 수 있음 — 모든 환율 앱이 그래요).
